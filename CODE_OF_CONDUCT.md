# Code of Conduct

This project follows a short version of the
[Contributor Covenant](https://www.contributor-covenant.org/).

## Our pledge

We want participation in this project to be a welcoming, harassment-free
experience for everyone, regardless of experience level, background, or
identity. Many of you are writing your first pull request ever — that's what
this project is for.

## Expected behavior

- Be kind and patient, especially with first-time contributors.
- Give specific, actionable feedback on pull requests.
- Assume good intent; ask questions instead of making accusations.
- Respect that everyone is at a different point in their learning journey.

## Unacceptable behavior

- Harassment, insults, or personal attacks, public or private.
- Dismissive or demeaning comments on someone's code or questions.
- Any other conduct that would reasonably be considered inappropriate in a
  professional setting.

## Enforcement

If you experience or witness unacceptable behavior, please let a workshop
organizer or maintainer know. Reports will be handled promptly and
confidentially.

## Scope

This Code of Conduct applies within project spaces (issues, pull requests,
discussions) and in public spaces when someone is representing the project.
